## Key discoveries
- **`page.content()` nav-race:** a bare-origin `goto('/')` under `baseURL=…/autotable/` resolves to the origin root, which the backend serves as a `<meta http-equiv="refresh">` bouncer (`wwwroot/index.html`) → any `page.content()` in that window throws. Fixed via RELATIVE gotos (`'./'`, `'./?action=…'`) + a shared `safeContent()` retry helper (new `tests/e2e/_helpers.ts`).
- **visual-regression was harness, not a render/CSP bug** (render is correct under `style-src 'self'`): replaced CSP-blocked `addStyleTag({content})` with `toHaveScreenshot({ animations:'disabled' })`; fixed `snapshotPathTemplate` to lead with `{testDir}` (empty `{testFileDir}` collapsed to filesystem root → mkdir EACCES); gated on baseline existence via `existsSync(testInfo.snapshotPath())` (Playwright missing-baseline is an un-catchable softError).

## Conventions established (durable, team-wide)
- NEVER bare-origin `goto('/')` in e2e; use relative paths + read content via `safeContent()`.
- Under Production CSP (`style-src 'self'`), do NOT `addStyleTag({content})` — use `toHaveScreenshot({ animations:'disabled' })`.
- `snapshotPathTemplate` MUST lead with `{testDir}`/`{snapshotDir}`, never `{testFileDir}` for specs sitting directly in `testDir`.
