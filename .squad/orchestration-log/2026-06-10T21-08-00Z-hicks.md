## Key discoveries

### V1↔V2 drawer dual-existence
Legacy drawer only mounts inside game. V2 is canonical for lobby + cross-app. Always wire lobby through `#settings-button`, never `#settings-toggle`.

### V2 drawer tab-gating
Default `activeTab = 'general'`. Audio/Display/Network controls require activating tab first. Created `activateAudioTab()` helper pattern.

### Identity cache key drift
`mahjong.identity.cache.v1` is source-of-truth; code reading `mahjong.profile.cache.v1` silently misses. Identity-avatar-migration modal now subscribes to both + reads LS directly as fallback.

### CRITICAL INFRA FINDING
Backend serves static files from `/data/source/mahjong-autotable/src/frontend/autotable/` regardless of which worktree built them. After every `npm run build` in non-main worktree, agents MUST rsync the dist:
```bash
rsync -a --delete <worktree>/src/frontend/autotable/ /data/source/mahjong-autotable/src/frontend/autotable/
```
This explains why initial wave fixes appeared to no-op for hours.
