## Production discoveries (not just test fixes)

### Bug 1: Lobby lazy-mount race (Ferro)
Playwright's `click()` fires `mouseenter` first, consuming `{once:true}` handler. Subsequent click calls `load()` which early-returns. **Affected real users**: hover-then-click on settings gear was a silent no-op.

**Root:** `src/frontend/autotable-src/src/lobby.ts:scheduleSettingsDrawerLazyMount`
**Fix:** Sticky `loadPromise` + synth-click in handler

### Bug 2: OAuth provider envelope drift (Bishop)
Backend returns `{id, displayName, enabled, kind}` objects; frontend expected legacy string array. Every OAuth button silently hidden in real deploys.

**Root:** `src/frontend/autotable-src/src/auth.ts:intersectProviders` + `src/backend/src/Mahjong.Autotable.Api/Auth/AuthController.cs:65–80`
**Fix:** Teach consumer to accept both object and string shapes

### Bug 3: ELO fallback banner unreachable (Bishop)
`fetchOnce` on 404 flips `state.mode = 'stats'` BEFORE render; render guard on both mode + data becomes dead code.

**Root:** `src/frontend/autotable-src/src/leaderboard.ts:fetchOnce`
**Fix:** Gate on data-availability alone, not mode

## Critical infra finding (Hicks)

Backend serves static files from `/data/source/mahjong-autotable/src/frontend/autotable/` regardless of which worktree built them. Non-main worktree agents must rsync after `npm run build`:

```bash
rsync -a --delete <worktree>/src/frontend/autotable/ /data/source/mahjong-autotable/src/frontend/autotable/
```

This explains why initial fixes appeared to no-op for hours.
