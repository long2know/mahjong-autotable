API Endpoints Used (Program.cs)
================================
POST /api/game/                    - Create game (returns hostPlayerId)
POST /api/game/{id}/join           - Join game (returns playerId)
POST /api/game/{id}/start          - Start game (host only)
GET  /api/game/{id}/state          - Fetch game state
POST /api/game/{id}/draw           - Draw tile
POST /api/game/{id}/discard        - Discard tile
POST /api/game/{id}/meld           - Declare meld
POST /api/game/{id}/win            - Declare win

SignalR Hub: /hubs/game
Events: PlayerJoined, GameStarted, TileDrawn, TileDiscarded, MeldDeclared, GameWon

Routing Flow (main.ts)
======================
1. Parse URLSearchParams at startup
2. If no ?game= → mountLobby(), exit early
3. If ?game= → initialize 3D scene (Phases 0-4 path)
4. Subscribe to state changes:
   - If status='Waiting' → showWaitingOverlay()
   - If status='Active' → hideWaitingOverlay()
   - If status='Completed' → show game end overlay


Lobby → Game Flow
==================
User visits http://localhost:5173/
       ↓
   Lobby UI
       ↓
 Fill "Create Game" form
       ↓
 POST /api/game/ { hostName, mode, botSeatCount }
       ↓
 Server returns { id, hostPlayerId }
       ↓
 Redirect to ?game={id}&player={hostPlayerId}
       ↓
 3D scene loads
       ↓
 Fetch GET /api/game/{id}/state → status='Waiting'
       ↓
 Waiting overlay shows
       ↓
 Click "Start Game" → POST /api/game/{id}/start
       ↓
 Server triggers GameStarted event → status='Active'
       ↓
 Waiting overlay dismisses
       ↓
 Gameplay begins


Join Flow (separate player)
============================
User visits http://localhost:5173/
       ↓
   Lobby UI
       ↓
 Fill "Join Game" form (paste game ID, name, seat)
       ↓
 POST /api/game/{id}/join { name, seat }
       ↓
 Server returns { id (playerId), gameId }
       ↓
 Redirect to ?game={gameId}&player={playerId}
       ↓
 3D scene loads
       ↓
 Fetch state → status='Waiting'
       ↓
 Waiting overlay shows (non-host sees waiting message)
       ↓
 Wait for host to start...
       ↓
 GameStarted event → status='Active'
       ↓
 Overlay dismisses, gameplay begins
